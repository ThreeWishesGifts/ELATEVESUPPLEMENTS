# Elateve Wellness

Marketing site for Elateve Wellness — precision oral nutrition for a woman's continuous biological journey.

Static site, no build step: `index.html`, `css/styles.css`, `js/script.js`.

## Local preview

Serve the folder with any static file server, e.g.:

```bash
npx http-server -p 5173
```

## Deployment

Deployed to Hostinger via Git auto-deploy from this repository's `main` branch.

## Structure

- `index.html` — single-page site: hero, brand promise, the 5 product phases, Phase Finder quiz, clinical section, reviews, brand story, waitlist, footer
- `css/styles.css` — design tokens and styles
- `js/script.js` — Phase Finder quiz logic, nav toggle, popup teaser, waitlist form
- `assets/` — favicon and brand assets
